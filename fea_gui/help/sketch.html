Sketcher (1D / 2D without CAD)

Draw a 2D section (plane stress, plane strain, axisymmetric) or a beam system directly in the program: lines, arcs, circles, rectangles and polylines from typed coordinates and named parameters. For quick hand checks, teaching and variants. There is no constraint solver – a point is where its two expressions say; a parameter change moves everything that uses it.

Starting

  • File → New 2D model from sketch… or New beam system from sketch… (also buttons in the Model step). Choose the problem type, the thickness (2D) or the plane (beams) and draw.
  • Model → Edit sketch… changes the drawing of an existing sketch model. The setup is kept: constraints, loads, materials and mesh settings follow the entities (see below).
  • Tools → Program modules → Sketcher: DXF import adds the optional ezdxf for the DXF import; the sketcher itself needs only the module beams (shapely).

2D sketches

  • The closed contours form regions; every region is a part (name it in the table Regions, or the parts are called Region 1 …). A line that splits a region makes two parts that can have different materials; a circle or rectangle inside a region is a hole.
  • Plane stress / plane strain: the part is extruded by the thickness (symmetric about the sketch plane); axisymmetric: x = radius, y = the axis (drawn dash-dotted), the part is revolved by 360°. Loads and reactions of an axisymmetric model are for the whole circumference. Nothing may lie at x < 0.
  • The 2D analysis is the ordinary one (2D section analysis); constraints and loads are set on the edges by their names in the usual steps.
  • Make 3D (MCP fea_sketch_to_3d) turns the regions into a normal 3D study by extrusion or revolution.

Beam sketches

  • Points become nodes (named like the point, P2), lines and arcs become members (named like the entity, E3). The plane is by default the vertical plane XZ (x right, y up = global Z).
  • Section and material per entity or the default of the sketch; a section changed in the Members step stays when the sketch is built again. Supports of the sketch nodes are managed by the sketch.
  • The nodes are held against motion out of the plane of the sketch (switchable), so a plane frame loaded in its plane is solved by the program's own beam solver.

Changing a parameter keeps the setup

Applying a changed sketch goes through the geometry remap of the program (geometry replacement): the side faces of every entity are recognised by the entity id, not by guessing, so constraints, loads, materials, mesh refinements and the mesh size are kept. What disappeared (a deleted entity, a vanished region) is reported with its name. The sketch is stored in the study file; the parameters are the inputs of a later parametric study.

Errors

The message names the entity: an open contour (with the size of the gap and the neighbour), a polyline that crosses itself, a free line, a contour across the axis, a region of zero area. The entities concerned are drawn red.
