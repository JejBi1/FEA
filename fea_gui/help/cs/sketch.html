Náčrtník (1D / 2D bez CADu)

Nakreslete 2D řez (rovinná napjatost, rovinná deformace, rotační symetrie) nebo prutovou soustavu přímo v programu: úsečky, oblouky, kružnice, obdélníky a lomené čáry z psaných souřadnic a pojmenovaných parametrů. Pro rychlé ruční kontroly, výuku a varianty. Žádný řešič vazeb tu není – bod leží tam, kam říkají jeho dva výrazy; změna parametru posune vše, co ho používá.

Spuštění

  • Soubor → Nový 2D model z náčrtu… nebo Nová prutová soustava z náčrtu… (také tlačítka v kroku Model). Zvolte typ úlohy, tloušťku (2D) nebo rovinu (pruty) a kreslete.
  • Model → Upravit náčrt… změní výkres existujícího modelu z náčrtu. Nastavení zůstane: vazby, zatížení, materiály a nastavení sítě sledují entity (viz níže).
  • Nástroje → Moduly programu → Náčrtník: import DXF přidá volitelný balíček ezdxf pro import DXF; samotný náčrtník potřebuje jen modul beams (shapely).

2D náčrty

  • Uzavřené obrysy tvoří oblasti; každá oblast je část (pojmenujte ji v tabulce Oblasti, jinak se jmenují Region 1 …). Úsečka, která oblast rozdělí, vytvoří dvě části s možností různých materiálů; kružnice nebo obdélník uvnitř oblasti je otvor.
  • Rovinná napjatost / deformace: část se vytáhne o tloušťku (souměrně podle roviny náčrtu); rotační symetrie: x = poloměr, y = osa (čerchovaně), část se otočí o 360°. Zatížení a reakce rotačního modelu jsou pro celý obvod. Nic nesmí ležet na x < 0.
  • 2D výpočet je obvyklý (2D řez); vazby a zatížení se zadávají na hranách podle jmen v obvyklých krocích.
  • Udělat 3D (MCP fea_sketch_to_3d) změní oblasti na běžnou 3D studii vytažením nebo rotací.

Prutové náčrty

  • Body se stanou uzly (jmenují se jako bod, P2), úsečky a oblouky pruty (jmenují se jako entita, E3). Rovina je výchozí svislá XZ (x doprava, y nahoru = globální Z).
  • Průřez a materiál podle entity nebo výchozí hodnota náčrtu; průřez změněný v kroku Pruty zůstane, když se náčrt sestaví znovu. Podpory uzlů náčrtu spravuje náčrt.
  • Uzly jsou drženy proti pohybu z roviny náčrtu (lze vypnout), takže rovinný rám zatížený ve své rovině řeší vlastní prutový řešič programu.

Změna parametru zachová nastavení

Použití změněného náčrtu jde přes přemapování geometrie programu (výměna geometrie): boční stěny každé entity se poznají podle id entity, ne hádáním, takže vazby, zatížení, materiály, zjemnění sítě a velikost sítě zůstanou. Co zmizelo (smazaná entita, zaniklá oblast) se ohlásí se jménem. Náčrt se ukládá do souboru studie; parametry jsou vstupy pozdější parametrické studie.

Chyby

Hlášení jmenuje entitu: otevřený obrys (s velikostí mezery a sousedem), lomená čára, která protíná sama sebe, volná čára, obrys přes osu, oblast s nulovou plochou. Dotčené entity jsou nakresleny červeně.
